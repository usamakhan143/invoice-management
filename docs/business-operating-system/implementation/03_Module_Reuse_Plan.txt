8. SERVICE PATTERN TO COPY
================================================================================

    Primary template: services/expenseReturnService.ts
        • Class-based service with static methods
        • FieldValue.increment / Timestamp.now()
        • companyId on every document
        • ActivityLogger.log after successful write
        • Validation before Firestore write

    Secondary template: services/campaignService.ts
        • subscribeXxx(callback) for real-time lists
        • companyId-scoped queries

    Do NOT copy: ExpensesPage inline Firestore (anti-pattern for BOS)


================================================================================
9. REPORTS ENRICHMENT VS REBUILD
================================================================================

    ENRICH (do not rebuild):
        • ReportsPage Expenses tab — add "Initiative" column via bosReportJoin
        • ReportsPage — new "Initiative spend" tab (aggregated by initiativeId)
        • DashboardPage — "Top initiatives by spend" card (reuse totalsByCurrency)
        • CSV exports — append initiativeName, ventureName columns

    DO NOT REBUILD:
        • Cashflow, loans, deposits, integrity tabs
        • balanceIntegrityService
        • Existing expense/return calculations

    NEW (not replacement):
        • BosDecisions list export (Phase 1 minimal)
        • BosMetricSnapshot dashboard (Phase 2 — do not start in P1)
