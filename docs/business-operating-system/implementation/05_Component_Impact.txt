5. UX FLOWS — PHASE 1
================================================================================

Flow A: Finance attributes expense (Option C)
    1. User opens ExpensesPage (unchanged list/filter)
    2. Opens expense detail (existing modal)
    3. Sees "Not attributed" or InitiativeBadge
    4. Clicks "Attribute to initiative" (permission gated)
    5. AttributionModal: VentureSelector → InitiativeSelector → Confirm
    6. bosAttributionService.create → ActivityLogger
    7. Badge updates on modal close

Flow B: Owner creates initiative
    1. Sidebar → Initiatives → New initiative
    2. Select venture, name, hypothesis, status draft→active
    3. Initiative detail shows linked attributions (empty initially)

Flow C: Reports enrichment
    1. User opens Reports → Expenses tab (existing)
    2. If bos_reports_view: extra "Initiative" column
    3. Export CSV includes initiative name column

Flow D: Decision log (minimal P1)
    1. Initiative detail → Decisions tab
    2. Add decision title + context + outcome
    3. List on initiative; no scoring engine in P1
