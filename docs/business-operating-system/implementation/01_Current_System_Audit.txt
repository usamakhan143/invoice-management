6. COMPANY TENANCY MODEL (CRITICAL FOR BOS)
================================================================================

    resolveCompanyIdForUser(user, profile):
        Owner → user.uid
        Team member → profile.companyId (owner's uid)

    getExpenseCompanyId(user, profile):
        Same logic (duplicate helper in expenseCompanyScope.ts)

    Expense query scoping:
        Company-wide: expenses.where("companyId", "==", companyId)
        Own-only: expenses.where("userId", "==", uid)

    BOS implication:
        All new collections MUST use companyId field with same resolution.
        BosVenture is NOT the same as companyId — one company may host
        multiple BosVentures in future (Doc 10). Today: 1 company ≈ 1 founder
        tenant; multiple ventures share same companyId.

================================================================================

    Load pattern: Promise.all companyId queries → useState arrays
    Filter: inRange() client-side on Timestamp fields

           accounts, integrity

    Permissions: REPORTS_VIEW, REPORTS_EXPORT

    No server aggregation. No charts. No BI dimensions.
