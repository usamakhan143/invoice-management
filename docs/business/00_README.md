# Business Documentation

## Purpose

This folder contains **founder and business-facing documentation** for the company. It is separate from:

- **Technical / BOS architecture** — `docs/business-operating-system/` (frozen Version 1.0)
- **Implementation planning** — `docs/business-operating-system/implementation/`
- **Application code** — React + Firebase ERP

These documents capture **how the business operates**, **who it serves**, **how it grows**, and **what it learns** — not how the software is built.

## Audience

- Founder / leadership
- Sales, marketing, and delivery leads (as the team grows)
- Future hires onboarding to business context

## How to use this folder

1. Fill placeholders as decisions are made — do not invent facts in advance.
2. Keep documents living: update when strategy, offers, or ICP change.
3. Link business decisions to `10_Decision_Log.md` and learnings to `11_Lessons_Learned.md`.
4. Terminology here is **business language**. For BOS/ERP technical terms, see `docs/business-operating-system/10_Domain_Glossary.txt`.
